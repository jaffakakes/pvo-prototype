PVO SDK

Release 0.1 prototype

PVO is a self-contained interactive video file. One .pvo package carries the main media, every possible branch, components, conditions, and a declarative manifest without depending on Restyle or any particular editor, payment provider, or server.

quick-start.js
import {
  packPvoProject,
  readPvo,
  validatePvo,
  createPvoRuntime
} from "@pvo/sdk";

const check = validatePvo(manifest);
if (!check.valid) throw new Error(check.errors.join("\n"));

const pvo = await packPvoProject({
  manifest,
  assets: [
    { id: "main", file: mainVideo },
    { id: "yes_branch", file: yesVideo },
    { id: "no_branch", file: noVideo }
  ]
});
const decoded = await readPvo(pvo);
const runtime = createPvoRuntime(decoded.manifest, hostAdapters);

The manifest is the program

The boundary is part of the design

The SDK describes interaction; products decide what that interaction means.

PVO owns

Packaged media, timelines, scenes, UI descriptions, state, conditions, generic requests, and response mapping.

The host owns

Rendering choices, accounts, servers, payments, databases, analytics, moderation, and any brand-specific behavior.

Deferred

Signing, builder layers, offline queues, native bindings, collaboration, and AI authoring.
